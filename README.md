# PooPooCat

Kitty Catty! It's Pooping Time! Decorate your own kitty poopoo and poop it out!

## Play

Open `index.html` in a browser. Use **P** or **space** to "Push!" or "Start!", and **R** to restart. Touch, mouse pointer and keyboard movement are supported on mobile and computer.

1. Start Screen
   - Pixel-art title: "Poo Poo Cat"
   - Animated angel cat with halo and wings
   - Start button
   - Keyboard and mouse support

2. Food for Poop
   - Select one of four foods:
     • Rice (Easy)
     • Beetroot (Normal)
     • Corn (Hard)
     • Dragon Fruit (Expert)
   - Food choices affect the behavior, appearance, and difficulty of the pooping challenge
  
3. Pooping Time
   - Push using the touch on mobile, mouse pointer or Spacebar
   - Progress meter moves according to the selected food
   - Stop within the green target zone at 0.3kg to succeed
   - Receive a success or fail result screen

## Controls

Mouse Click
- Start game
- Select food
- Push
- Restart

Spacebar
- Start game
- Push during gameplay

## Objective

Feed the angel cat.
Push carefully.
Hit the 0.3kg target.
Poop the legendary perfect Poo Poo.
