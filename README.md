# PooPooCat

Kitty Catty! It's Pooping Time! Decorate your own kitty poop and poop it out!

## Play

Open `index.html` in a browser. Use **Left/Right** or **A/D** to move, **P** or **space** to pause, and **R** to restart. Touch and pointer movement are supported on mobile.

Build step and dependencies are required.
